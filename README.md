# 🃏 Jogo da Memória

Um jogo da memória feito com HTML, CSS e JavaScript puro — sem instalação, sem frameworks, só abre no navegador!

## 🎮 Como jogar

1. Clique em qualquer carta para virá-la
2. Tente encontrar o par igual
3. Encontre todos os pares para ganhar!

## 🚀 Como rodar

Basta abrir o arquivo `index.html` no seu navegador. Não precisa instalar nada!

## ✨ Funcionalidades

- 3 níveis de dificuldade (Fácil, Médio, Difícil)
- Contador de jogadas e tempo
- Sistema de pontuação
- Animações de flip nas cartas
- Design responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3 (animações, grid, variáveis CSS)
- JavaScript (sem bibliotecas externas)

## 📁 Estrutura

```
jogo-da-memoria/
└── index.html   ← tudo em um arquivo só!
```
